# Frontend

Vue 3 + Vite + Pinia + Vue Router application for the NGO Intelligence Suite.

```powershell
# from repo root
npm run dev:frontend
```

Dev server: `http://localhost:5173` (proxies `/v1` to the API gateway on `:3000`).

Design authority: [`docs/sdd/19-frontend-architecture.md`](../docs/sdd/19-frontend-architecture.md).
